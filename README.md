# sheep-game-data

《消灭萌萌怪》（羊了个羊本地版）的数据仓库，游戏把这里当只读数据库用：

- `announcements.txt`：公告。每条公告两行（标题行、内容行），中间用一行 `---` 分隔；格式 `标题【】标题文字`、`内容【】内容文字`，标题和内容都支持 HTML（加粗、颜色、图片等）。音乐直链：在文件任意位置单独一行 `音乐【】https://...mp3`。
- `codes.txt`：兑换码提示表。每行 `兑换码=提示标题=过期时间YYYYMMDD`。

改完提交（commit）后，游戏下次打开就会拉到新内容（GitHub Pages/raw 有几分钟缓存，稍等即可）。
