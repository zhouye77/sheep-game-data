# sheep-game-data

《消灭萌萌怪》（羊了个羊本地版）的数据仓库，游戏把这里当只读数据库用：

- `announcements.txt`：公告。格式重点：**实际内容写在【】括号里面**，括号前面的字是字段标签（可带编号）。例子：
  - `公告标题1【测试】`
  - `公告内容1【在测试中，1213`（内容可以跨多行，直到】结束）`】`
  - `音乐【https://...mp3】`（公告音乐直链，放任意位置）
  【】外面的文字会被忽略。标题和内容都支持 HTML（加粗、颜色、图片等）。遇到下一个“标题”标签就算新的一条公告。
- `codes.txt`：文本兑换码表（通用码不用卡密生成器，直接在这里加行）。每行 `类型=兑换码=提示标题=过期时间YYYYMMDD=次数=萌币数量`。类型：1=绑定码（不看次数，每台设备只能兑一次）、2=通用码。次数：0=无限次、1=一次、N=N次（按本机记录计次）。兑换成功发最后一列的萌币数量并弹出提示标题。生成器出的 YY2- 加密码仍走游戏原有验码，不受此表影响。

改完提交（commit）后，游戏下次打开就会拉到新内容（raw 文件有几分钟缓存，稍等即可）。
- `config.txt`：游戏配置，沿用【】格式：`邀请奖励【100】` 是每成功邀请一位好友、双方各得的萌币数；`里程碑N人【萌币数】` 是阶段性奖励，可写多行（邀请满 N 位不同的好友可领一次）。
