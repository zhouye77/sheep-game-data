# sheep-game-data

《消灭萌萌怪》（羊了个羊本地版）的数据仓库，游戏把这里当只读数据库用：

- `announcements.txt`：公告。格式重点：**实际内容写在【】括号里面**，括号前面的字只是字段名。每条公告两行——`公告标题【标题文字】`、`公告内容【内容文字】`，条与条之间用一行 `---` 分隔。标题和内容都支持 HTML（加粗、颜色、图片等）。音乐直链：在文件任意位置单独一行 `音乐【https://...mp3】`。
- `codes.txt`：兑换码提示表。每行 `兑换码=提示标题=过期时间YYYYMMDD`，兑换时游戏来查：查到了按这里的过期时间算、成功后弹出提示；没查到就不弹提示、也不按这里限制时间。

改完提交（commit）后，游戏下次打开就会拉到新内容（raw 文件有几分钟缓存，稍等即可）。
