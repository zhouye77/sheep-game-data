# sheep-game-data

《消灭萌萌怪》（羊了个羊本地版）的数据仓库，游戏把这里当只读数据库用：

- `announcements.txt`：公告。格式重点：**实际内容写在【】括号里面**，括号前面的字是字段标签（可带编号）。例子：
  - `公告标题1【测试】`
  - `公告内容1【在测试中，1213`（内容可以跨多行，直到】结束）`】`
  - `音乐【https://...mp3】`（公告音乐直链，放任意位置）
  【】外面的文字会被忽略。标题和内容都支持 HTML（加粗、颜色、图片等）。遇到下一个“标题”标签就算新的一条公告。
- `codes.txt`：兑换码提示表。每行 `兑换码=提示标题=过期时间YYYYMMDD`，兑换时游戏来查：查到了按这里的过期时间算、成功后弹出提示；没查到就不弹提示、也不按这里限制时间。

改完提交（commit）后，游戏下次打开就会拉到新内容（raw 文件有几分钟缓存，稍等即可）。
